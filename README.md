# TestingGame

One of my older C++/SFML projects.

I used it to learn how to split game logic from rendering and input instead of keeping everything in one main loop. It has a small state machine, projectile movement and some basic tests around the game logic.

## what I worked on

- C++ game logic
- SFML
- simple state machine
- projectile physics
- separating logic from rendering/input

## status

old learning project. I’m keeping it here because it shows how I was learning C++ and structuring a bigger program, but it isn’t something I’m actively developing now.
